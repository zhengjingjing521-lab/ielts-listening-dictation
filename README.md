# 雅思单词听写

支持英中跟读、逐词听写、自动错词本和 Excel 导出的电脑学习工具。可作为 Obsidian 桌面插件使用，也可通过本地浏览器练习；随包提供多人 HTTPS 网站部署配置。

当前版本：**1.1.8**。

## 功能

- **词表学习**：9 套词表、50 个分组，共 2,143 个词表位置（包含重复词）。可查看英文和中文释义，遮住英文或中文自测，练习写英文、写中文，以及首次作答计分。
- **离线英中跟读**：英音 Sonia、美音 Jenny 可选；看词学习时先读英文，再接晓晓普通话释义。支持重复播放、调整重复间隔和上下方向键换词。
- **逐词听写**：播放英文、输入拼写、回车批改；支持 0.85 倍慢速、未听出、遮住重写、下一词、整组重练和本组错词复练。听写、遮词、写中文和首次计分模式只播放英文。
- **规范拼写判分**：按当前词表接受经过审核的替代写法，例如 colour / color；部分变体按具体词义判断。保存实际输入。
- **自动错词本**：表格判错、逐词听写写错或未听出会自动收录。可集中练习、搜索已有词条补录；答对后保留，移出前确认并可撤销。
- **全词表搜索**：按部分英文或已有中文释义查找，英文搜索忽略大小写，直接定位到词条所在分组。
- **记录与导出**：逐词听写保存每次原始作答、时间、结果、错误和音色；订正不覆盖旧记录。Excel 包含每日单词汇总与逐次作答明细。

## 下载完整安装包

进入本仓库右侧 **Releases**，下载 `ielts-listening-dictation-1.1.8.zip`，解压后阅读 `部署指南.md`。三份 `media/` 音频 ZIP 保持原样。

随包提供 1,839 段英音、1,839 段美音和 1,780 段中文释义音频，共 5,458 段。安装 Python 依赖需要联网；安装完成后，本机学习、发音和 Excel 导出可以离线使用，无需 API 密钥。

## 在本地浏览器快速开始

需要 Python 3.10 或更高版本，推荐 Python 3.12。在解压后的插件目录创建虚拟环境并安装依赖。

### Windows PowerShell

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

### macOS / Linux

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

打开 <http://127.0.0.1:43219/>，关闭服务按 Ctrl+C。默认练习数据位于系统用户主目录下的 `.ielts-dictation/`；可用 `--data-dir` 指定专用目录。

## 在 Obsidian 中使用

将完整 `ielts-listening-dictation` 文件夹复制到目标库的 `.obsidian/plugins/`，在最终安装位置创建虚拟环境并安装依赖，然后在 Obsidian 的第三方插件设置中启用「雅思单词听写」。点击左侧耳机图标或使用「打开雅思单词听写」命令。

需要桌面版 Obsidian。各库练习数据存放于库根目录 `IELTS Dictation Data/`；备份前先关闭插件并复制整个数据目录。已有同 ID 个人版本时，请先用空库试装。

完整步骤、迁移注意事项和多人网站部署方法见 [部署指南](部署指南.md)。

## 多人网站

提供 `Dockerfile`、`compose.yaml` 和 `Caddyfile`。准备服务器和独立域名后，可按部署指南启动 HTTPS 网站。完整功能包含 Python 服务和 SQLite 数据库，GitHub Pages 单独托管静态文件无法运行完整练习。

公网模式按浏览器 Cookie 隔离记录；当前没有账号登录、跨设备同步和换设备找回。清除 Cookie 或更换浏览器配置会获得新身份。运营者需要自行说明数据保留与删除方式。
